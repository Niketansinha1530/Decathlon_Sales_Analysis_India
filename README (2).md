# Decathlon Sales Analysis – India

A Power BI project analysing the sales performance of Decathlon's Indian division, covering products, stores and sales data.

## Dashboard Preview

![Decathlon Sales Dashboard](DashboardImage/YOUR_IMAGE_NAME.png)

## Project Overview

This project turns raw sales, product and store data into an interactive Power BI dashboard. The goal is to help understand how sales are performing and to support better business decisions.

## Objectives

- Track overall sales performance
- Analyse sales by product and category
- Compare performance across stores and locations
- Identify trends and top-performing areas

## Tools Used

- **Microsoft Power BI** – data modelling, DAX and dashboard
- **Microsoft Excel** – source data (products, sales, store)

## Data Sources

The Excel files used in this project are stored in the `ExcelResource` folder:

- `products.xlsx` – product details
- `sales.xlsx` – sales transactions
- `store.xlsx` – store information

## How to Use

1. Clone or download this repository:
   ```
   git clone https://github.com/Niketansinha1530/Decathlon_Sales_Analysis_India.git
   ```
2. Open `Decathlon_Sales_Analysis.pbix` in **Power BI Desktop**.
3. If Power BI asks for the data location, point it to the files in the `ExcelResource` folder (Transform data → Data source settings).
4. Explore the dashboard using the filters and slicers.
